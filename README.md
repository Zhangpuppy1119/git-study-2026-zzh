Git 学习实践笔记
姓名：张梓涵 班级：24数媒1班
1. 学习资料来源
- Git官方文档：https://git-scm.com/doc
- GitHub新手教程：https://docs.github.com/zh/get-started

 2. 实践流程
1. 安装Git并配置用户名、邮箱
2. 注册GitHub账号，创建公开仓库
3. 本地初始化仓库，完成3次有效提交
4. 将本地仓库推送到远程GitHub仓库

 3. 提交说明
- 第1次提交：创建test.txt文件，初始化本地仓库
- 第2次提交：修改test.txt文件，添加内容
- 第3次提交：完善test.txt文件，完成3次提交要求

 4. 遇到的问题及解决方法
1. 问题：配置Git用户名时出现`invalid key`报错
   解决：`user.name`和用户名之间少了空格，修正命令后成功配置
2. 问题：第一次推送GitHub时提示权限不足
   解决：确认仓库是公开的，并且用GitHub账号完成了登录授权

 5. 学习心得
通过本次Git实践，我掌握了Git的基础配置、本地提交、远程推送的完整流程，理解了版本管理的作用，为后续的项目协作打下了基础。
